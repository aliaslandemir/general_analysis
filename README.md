# General Data Analysis

A collection of Python notebooks exploring data analysis, statistical methods, machine learning, numerical computing, and scientific visualization.

## Topics
- Data cleaning, processing, and exploratory analysis
- Descriptive and inferential statistics
- Parametric and non-parametric hypothesis testing
- Regression, classification, and clustering
- Machine learning and model evaluation
- Numerical methods and simulations
- Uncertainty quantification and bootstrap methods
- Sensitivity analysis and optimization
- Scientific data visualization

## Tools
Python, NumPy, Pandas, SciPy, Scikit-learn, Matplotlib, Seaborn, Statsmodels, and Jupyter.

## Purpose
Develop and demonstrate practical skills in scientific computing, statistical analysis, and data-driven modeling using reproducible Python workflows.
